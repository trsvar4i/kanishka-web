# Kanishka — проверка готового интерфейса

Дата: 16 ноября 2026.

Проверка выполнена в отдельном Chromium 151.0.7922.34 через Playwright 1.62.1. Использован тестовый профиль, без доступа к пользовательским вкладкам и cookies.

## Результат

- 45 сочетаний: главная, каталог и изделие; RU / EN / UZ; ширины 320, 375, 390, 768, 1440 px.
- 171 автоматическая проверка прошла.
- Горизонтального переполнения страницы и пересечений названий с ценами нет.
- axe-core 4.10.3: в девяти проверенных страницах/состояниях не найдено нарушений выбранных правил WCAG 2 A/AA, 2.1 A/AA, 2.2 AA и best practices.
- Шесть основных экранов дополнительно просмотрены визуально: главная, каталог и изделие на 1440 × 1000 и 390 × 844.
- Сохранены снимки всей страницы и первого экрана до и после исправлений.

Машинный результат: [after-metrics.json](after-metrics.json). Исходный замер: [before-metrics.json](before-metrics.json).

## Что обнаружено и исправлено

| Проблема | Исправление |
| --- | --- |
| Кнопка коллекции на главной находилась почти у нижнего края крупного снимка | Перенесена сразу под представление бренда; проверена видимость без прокрутки на 1440 × 900 и 1280 × 800 |
| На телефоне видны только две категории; остальные нужно искать горизонтальной прокруткой | Все пять категорий размещены с переносом строк, без скрытых пунктов |
| Заголовок каталога занимал много места до появления товаров | Уменьшены заголовок и вертикальные интервалы; больше места отдано изделиям |
| Длинные узбекские заголовки выходили за край страницы на 320–390 px | Заголовки и ссылки получили корректные переносы и размеры |
| Название ABDULLAJON пересекалось с ценой на 768 px | Шапка карточки переносит цену на следующую строку при нехватке места |
| Нижняя панель связи закрывала часть галереи и стрелок | Пока галерея или основная кнопка находятся на экране, панель скрыта; после просмотра изделия появляется |
| Выбранная стрелками фотография не прокручивала ленту миниатюр | Активная миниатюра остаётся видимой; вертикальная позиция страницы не меняется |
| Мобильное меню оставалось открытым после перехода к широкой версии | Меню закрывается при расширении окна; фокус переводится в настольную навигацию |
| Мобильное меню не закрывалось при нажатии вне шапки | Добавлено закрытие по внешнему нажатию и сохранено закрытие по Escape |
| Изображение одежды в разделе материалов обрезало силуэт | Показан полный исходный кадр |
| Непоследовательные уровни заголовков и вложенный aside в каталоге | Добавлен заголовок результатов и именованная область изделий; фильтры оформлены без лишнего landmark |
| Маленькие области нажатия на языки | Увеличены сенсорные области ссылок |
| Слишком крупный знак и поздний выбор категории на главной | Знак уменьшен; категории перенесены перед избранными изделиями |
| Много места до товаров в каталоге | Поиск и раскрытие настроек собраны в одну строку, выбранные параметры остаются видимыми |

Измерения последнего упрощения структуры: [structure-review](../structure-review/README.md).

## Проверенные действия

Выбор трёх подарочных бюджетов; сохранение выбора при смене языка; параметры каталога в URL; изменение и удаление фильтра; поиск и пустое состояние; сортировка по цене; сохранение фильтров между языками; меню и Escape; закрытие меню снаружи и при изменении ширины; галерея и прокрутка миниатюр; полный кадр и клавиатура; возвращение фокуса после закрытия фотографии; уход Watermelon/Radix; появление панели связи по контексту.

## Как повторить

При работающем локальном сайте из папки `ui`:

```sh
pnpm exec playwright install chromium --only-shell
pnpm test:browser
```

`BROWSER_BASE_URL` позволяет выбрать другой локальный адрес. `PLAYWRIGHT_BROWSERS_PATH` позволяет использовать существующий кэш Chromium. Текущая проверка использовала `/private/tmp/kanishka-playwright-browsers`.

Тест обновляет снимки `after-*` и `after-metrics.json`; исходные снимки `before-*` сохраняются.

## Пределы проверки

Это Chromium и эмуляция размеров окна. Safari, Firefox, реальные телефоны и скринридер не проверялись. Автоматический axe не доказывает полное соответствие WCAG. Lighthouse и скорость на боевом хостинге не измерялись.

Исходные фотографии из публичных публикаций остаются около 450 × 800 px. Проверка оригинальной публикации не дала большего разрешения; качество исходников не подменялось искусственной детализацией.
