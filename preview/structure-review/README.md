# Kanishka — упрощение структуры

Проверены главная и каталог в Chromium 151 на широком экране, ноутбуке и телефонной ширине. Работа касается иерархии, навигации и плотности интерфейса.

## Что изменилось

1. Знак на первом экране стал компактнее: на desktop его высота уменьшилась с 235 до 112 px. На телефоне знак остаётся в шапке, без второго повтора над фотографиями. Доступный заголовок страницы сохранён.
2. Выбор категорий размещён сразу после первого экрана, перед двумя избранными изделиями. Ссылки открывают каталог с выбранной категорией.
3. Шапка каталога сокращена. Поиск и кнопка фильтров находятся в одной строке; дополнительные настройки раскрываются по нажатию. Активные параметры и выбранная сортировка видны отдельными метками с удалением.

## Проверка поведения

Браузерный прогон прошёл: 171 проверка, 45 сочетаний страниц/ширин/языков, без ошибок. Проверены переходы из категорий главной в каталог, раскрытие фильтров настоящим нажатием, сортировка, отдельное удаление параметров, языки, бюджеты и галерея. axe не нашёл замечаний в проверенных состояниях.

Полная проверка и снимки страниц: [browser-review](../browser-review/README.md).

Safari, Firefox и реальные устройства этим прогоном не покрыты.
