# Kanishka — Astro + TypeScript + React

Локальная витрина бренда перенесена на Astro. Главная, каталог и 12 изделий формируются в готовый HTML на трёх языках: русский `/`, узбекский `/uz/`, английский `/en/`. Всего 42 страницы.

Новая визуальная система: графит, молочный цвет бумаги и красный из коллекции; компактный знак Kanishka, единая история ZARAFOT на первом экране и раздел мастерской в формате журнального разворота. Категории доступны перед избранными изделиями. Каталог, подборка подарков и страница изделия работают как React-острова; Watermelon UI используется для ухода за материалом.

## Запуск разработки

Нужен Node.js 24 (минимальное требование установленного Astro — 22.23.4) и pnpm 11.25.0.

```sh
cd ui
pnpm install --frozen-lockfile
pnpm dev
```

Локальный адрес: http://127.0.0.1:8081/. Изменения в исходниках обновляют сайт автоматически. Python для разработки больше не требуется.

## Проверки и сборка

Из папки `ui`:

```sh
pnpm check
pnpm build
pnpm test
```

`build` включает проверку типов и создаёт готовый сайт в `dist/` в корне проекта. `test` проверяет готовый HTML, локальные ссылки и гидратацию React в jsdom; предварительно нужна сборка. Установка зависимостей повторно нужна только после изменения package.json/lock-файла.

Для проверки в настоящем браузере при работающем локальном сайте:

```sh
pnpm exec playwright install chromium --only-shell
pnpm test:browser
```

Это отдельные инструменты разработки; обычная сборка и просмотр сайта не требуют Chromium. Браузерный тест проверяет 45 сочетаний страниц, языков и ширин, доступность axe и основные действия. Отчёт и снимки: `preview/browser-review/`.

Для просмотра сборки: `pnpm preview` из `ui` либо `python3 server.py` из корня. Выберите один сервер на порту 8081; перед сменой сервера остановите текущий. В установленном Astro 7 `pnpm dev` запускает фоновый сервер; управление: `pnpm exec astro dev status`, `pnpm exec astro dev logs`, `pnpm exec astro dev stop`.

В ограниченном окружении можно запускать команды с `ASTRO_TELEMETRY_DISABLED=1`, чтобы Astro не создавал пользовательские настройки вне проекта.

## Устройство проекта

- `ui/src/pages/` — маршруты Astro: главная, каталог, динамические страницы изделий и языков.
- `ui/src/layouts/SiteLayout.astro` — общий документ, метаданные, CSS, шапка и подвал.
- `ui/src/components/` — секции Astro и React-компоненты Catalog, GiftPicker, ProductExperience, ProductCard.
- `ui/src/components/ui/` — Watermelon/shadcn/Radix для блока ухода.
- `ui/src/data/` — единые типизированные товары, переводы, магазины и уход.
- `ui/src/lib/` — типы, маршруты, фильтры, цены, подборки, хранение состояния и данные для островов.
- `ui/src/scripts/site.ts` — небольшие общие действия: мобильное меню, языковые ссылки, копирование адреса, уведомления.
- `ui/src/styles/site.css` — вход в модульную систему стилей: fonts, foundations, navigation, home, catalog, product.
- `ui/public/assets/images/` — фотографии, логотип и иконки.
- `dist/` — результат сборки, не редактируется вручную.
- `reference/before-astro/` — сохранённая версия до переноса; прежний генератор и DOM-рендерер не подключены к новому сайту.
- `reference/before-editorial-redesign/` — исходники Astro до полного обновления визуальной системы.
- `reference/before-browser-polish/` — исходники перед исправлениями, найденными при проверке в Chromium.
- `reference/before-structure-refinement/` — исходники перед упрощением первого экрана и каталога.
- `preview/` — снимки прежних версий; `preview/browser-review/` — актуальный отчёт и снимки до/после браузерной проверки.

## Адреса и языки

Основные адреса: `/`, `/catalog/`, `/products/tokim-3/`; английские и узбекские страницы имеют префиксы `/en/` и `/uz/`. Языковые ссылки ведут на ту же страницу и сохраняют параметры каталога и якорь.

Фильтры остаются в URL. Возврат к каталогу восстанавливает подборку. Выбранный подарочный бюджет, фото изделия и раскрытый блок ухода сохраняются в sessionStorage при смене языка. Сайт продолжает работать, если браузер запретил доступ к хранилищу; в этом случае состояние между страницами не сохраняется.

Старые `/index.html` и `/catalog.html` поддерживаются локальным сервером; сборка сохраняет `catalog.html` как копию нового каталога, чтобы старые ссылки с бюджетом/фильтрами работали на статическом хостинге.

Метаданные, `lang`, canonical и hreflang формируются для каждой страницы. Перед публичной сборкой задайте реальный домен в `PUBLIC_SITE_URL` (пример в `ui/.env.example`); без него адреса в метаданных относительные. Домен, хостинг, платежи и склад не подключались.

- Astro/TypeScript: сборка и проверка без ошибок.
- 42 страницы: исходный HTML, заголовки, языки, метаданные, локальные изображения, ссылки и якоря.
- Гидратация React на разметке Astro без ошибок.

- Подарки: сначала бюджет, затем 3 / 4 / 3 соответствующих изделия.
- Галерея, клавиатура, полный кадр, фокус, Watermelon/Radix, Telegram, копирование ссылки, мобильное меню.
- HTTP-проверка локального Astro-сервера и прежних адресов.

Визуальная и сценарная проверка выполнена в Chromium 151: desktop/mobile, 45 сочетаний страниц, языков и ширин, 171 проверка и axe. Выявленные проблемы исправлены; отчёт со снимками до/после находится в `preview/browser-review/README.md`. Замеры изменений структуры — в `preview/structure-review/README.md`. Safari, Firefox, реальные устройства, скринридер и Lighthouse не проверялись.

Полный стек и предложения по дальнейшей работе — в `FRONTEND.md`.
