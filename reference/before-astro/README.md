# Kanishka — авторская мастерская, Ташкент

Локальный сайт-витрина Kanishka. Страница открывается без сборки: готовый React-компонент Watermelon UI и его стили лежат в `assets/vendor/`. Инструменты сборки нужны только для изменения компонентов в `ui/`.

## Запуск

```sh
python3 server.py
```

Откройте http://127.0.0.1:8081/. Сервер работает только на локальном IPv4-адресе и обрабатывает запросы в отдельных потоках. Другой порт можно указать явно: `python3 server.py 8090`.

## Текущая версия дизайна

Главная, коллекция и изделия разделены на отдельные страницы:

- `index.html` — представление бренда, подборка двух изделий, подробный раздел мастерской и материалов, три подарочные подборки и магазины.
- `catalog.html` — каталог с поиском, категориями, материалом, аудиторией и сортировкой.
- `products/<model>/index.html` — 12 самостоятельных страниц с прямыми ссылками, исходной HTML-разметкой, характеристиками и галереей.

В шапке используется настоящий знак из публичного канала Kanishka. Графитовая палитра сохранена; заголовки и основной текст используют спокойную типографику Golos Text. Фотографии материала и изделия заменили общий интерьер на первом экране.

У карточки название и цена стоят перед фотографией. Категории прокручиваются внутри своей панели, не растягивая страницу. На телефоне дополнительные фильтры свёрнуты, а у изделия название и цена размещаются перед галереей. Кнопка запроса наличия доступна в нижней панели.

Фильтры сохраняются в URL. Ссылка возврата со страницы товара восстанавливает последнюю подборку. Галерея поддерживает ракурсы, клавиатуру, полный кадр и запрос дополнительного фото. Кнопка «Поделиться» использует системное меню или копирует прямой адрес.

На главной раздел мастерской раскрывает работу с кожей, хлопковым канвасом и одеждой из хлопка: фотографии, пояснения к конструкции и рекомендации по уходу. В разделе подарков сначала выбирают бюджет, затем ниже появляется весь подходящий ассортимент с фотографиями, ценами и ссылками на изделия: низкий бюджет — до 200 000 сум, средний — 200 000–500 000 сум, высокий — свыше 500 000 сум.

Материал и уход размещены в контексте изделия; аккордеон Watermelon/Radix сохраняет состояние при смене языка. Поддерживаются RU / UZ / EN. Подключение и сборка описаны в `ui/README.md`.

HTML генерируется из общих шаблонов и данных. После изменений в каталоге или переводах выполните из `ui/`:

```sh
pnpm run build
```

Для обычного просмотра готового проекта сборка не требуется.

## Структура

- `index.html` — семантическая разметка страницы.
- `assets/css/styles.css` — токены, стили и адаптивная вёрстка.
- `assets/js/app.js` — фильтры, галерея, языки и взаимодействия.
- `assets/js/templates.js` — общие шаблоны карточек для генератора и браузера.
- `catalog.html`, `products/` — готовые страницы коллекции и изделий.
- `ui/scripts/generate-pages.mjs` — генератор 14 HTML-страниц.
- `ui/` — исходники Watermelon-компонента, конфигурация shadcn, сборка и проверка сценариев.
- `assets/vendor/` — готовый JS/CSS компонента, подключённый к странице.
- `DESIGN-BRIEF.md` — ответы пользователя и принятые решения.
- `assets/js/products.js` — реальные модели и филиалы.
- `assets/js/translations.js` — все переводы интерфейса.
- `assets/images/` — локальные фотографии и служебные SVG.
- `reference/` — прежние данные каталога.

## Проверка текущей версии

Прошли сборка Vite, TypeScript, синтаксис CSS, проверка переводов и локальных ссылок на всех 14 страницах, HTTP 200 для главной, каталога и всех 12 прямых адресов изделий.

Smoke-тест проверяет переходы по сформированным адресам, сохранение/восстановление фильтров, поиск, сортировку, бюджет подарков, галерею и клавиатуру, полный кадр, ссылку Telegram, «Поделиться», Watermelon/Radix и сохранение состояния при смене языка.

В браузере проверены новый первый экран и каталог, прямая страница изделия, переход назад с восстановлением фильтров, RU/EN/UZ. У страницы изделия измерены ширины 320, 390, 768 и 1440 px: горизонтального переполнения нет. После последней перестановки мобильного заголовка инструмент браузера стал недоступен; эта небольшая вертикальная перестановка отдельно визуально не перепроверена.

Изображения в `preview/` относятся к первой версии дизайна. Текущую версию смотрите на локальном сервере. Предыдущая версия исходников сохранена в `reference/design-v2/`.

Разделы мастерской и подарков проверены сборкой и smoke-тестом. Для выбора бюджета проверяются начальное состояние без товаров, подборки на 3/4/3 изделия, соответствие цен, сохранение фокуса и выбранного бюджета при смене языка. Визуальная проверка этих дополнений в текущей сессии недоступна.
